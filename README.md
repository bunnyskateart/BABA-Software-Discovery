# BABA 2 — Software Discovery

BABA 2 è un catalogo desktop per Windows che aiuta a scoprire software open source pubblicato su GitHub. Puoi esplorare le categorie, consultare i dettagli dei progetti e trovare i file di release adatti al sistema operativo che usi.

BABA 2 è un’applicazione per Windows. Può aiutarti a trovare anche programmi con release per macOS o Linux.

## Funzionalità

- Ricerca di progetti GitHub per nome o parole chiave.
- Esplorazione per categoria: produttività, sistema, giochi, social, blockchain, sviluppo, intelligenza artificiale, design e sicurezza.
- Schede con descrizione, publisher, sito ufficiale, licenza, popolarità e aggiornamento.
- Anteprime e screenshot quando disponibili.
- Argomenti cliccabili per esplorare categorie correlate.
- Elenco dei file pubblicati nelle release, con indicazione del sistema operativo quando riconoscibile.
- Download dei file di release direttamente da GitHub.
- Preferiti, cronologia, cache e download salvati sul dispositivo.
- Modalità notte, interfaccia compatta e suggerimenti configurabili.

## Scaricare BABA 2

Apri la pagina delle release e scarica **BABA 2.zip**:

[[Scarica BABA 2 dalle release](https://github.com/USERNAME/NOME-REPOSITORY/releases/latest)](https://github.com/bunnyskateart/BABA-Software-Discovery/releases/latest)

## Installazione e avvio

1. Estrai tutto il contenuto di `BABA 2.zip` in una cartella.
2. Lascia la cartella `_internal` accanto a `BABA 2.exe`.
3. Avvia `BABA 2.exe` oppure `Avvia BABA 2.bat`.

Non è necessario installare Python. BABA 2 è distribuito come archivio portatile e non include una procedura guidata di installazione.

## Come si usa

1. Cerca un programma o una funzione nella barra di ricerca, oppure scegli una categoria nella barra laterale.
2. Apri la scheda di un progetto per leggere i dettagli, consultare il sito ufficiale e vedere le immagini disponibili.
3. Nella scheda **Download**, scegli il file indicato per il tuo sistema operativo.
4. Conferma il download. Il file viene salvato nella cartella Download di BABA 2.
5. Usa **Preferiti** per ritrovare i progetti che vuoi consultare più tardi.

BABA 2 non avvia né installa automaticamente i file scaricati.

## Connessione e limiti API

BABA 2 non richiede login, password, token o account GitHub. Consulta i dati pubblici di GitHub; le ricerche sono quindi soggette ai limiti API applicati da GitHub. Per ridurre le richieste, BABA 2 riutilizza i risultati salvati nella cache locale.

## Dati sul dispositivo

Preferiti, cronologia, impostazioni, cache e file scaricati sono conservati localmente nella cartella dati di BABA 2, sotto `%LOCALAPPDATA%\BABA2`.

## Sicurezza

I file vengono scaricati dalle release pubblicate su GitHub e non sono eseguiti automaticamente. Prima di aprire un file, controlla il publisher, la pagina ufficiale del progetto e che il download sia adatto al tuo sistema.
